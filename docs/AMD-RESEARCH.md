# AMD / AMDL K线研究（0.7.1）

登录后先进入 `/home`，左侧提供原有「A股研究工作台」`/app`，右侧提供独立「AMD / AMDL 研究」`/backtest`。独立「股价对比」`/compare` 仍保留。`/backtest` 是管理员研究区，旧 `/research` 路径继续可用。AMD入口统一放在平台选择页右侧，与左侧A股工作台分开；`/market-data` 继续负责行情预览导入。原A股记录、策略ID、D0—D10和收盘定时任务不迁移、不清空。

## 使用

1. 选择 AMD / AMDL、行情数据集、美东日期范围和周期。分钟周期由同一来源1m生成；日线使用独立1d数据集。来源或复权口径不混合。
2. 可切换盘前、常规、盘后及美东/北京时间。图表支持缩放、拖动、十字光标、成交量、时间定位和重置。长分钟范围按页读取，不一次下载全年分钟数据。
3. 新建研究分组，点击K线或添加标记，选择买入、卖出、买回。默认人工假设；只有显式选择「用户报告成交」才视为用户提供的成交信息。OHLC参考值不会自动成为实际成交价。
4. 表格和图表相互定位；分组、日期、动作、状态可筛选。修改、删除、恢复及导入均保存服务端审计。相同股票/时间的不同标记保留独立ID。
5. CSV/JSON标记先预览再导入；导出包含原始时间、规范UTC时间、价格、来源和备注。已配对SELL/REBUY必须同分组同股票且卖出在先；未配对标记照常保存。统计只计标记和覆盖，不生成策略收益。

## 行情口径与已知范围

- 真实Longbridge POC：AMD、AMDL各有2025-10-28至2026-10-27的251条独立日线（日期与XNYS参考日历一致，价格仍未经独立源核验）；近期regular分钟各1000条（10/23从12:20美东开始，10/26和10/27完整常规时段）。AMDL有两条OHLC空白，保持missing；有量无价不代表停牌。
- 指定日期历史分钟查询返回301607，账号历史额度0。早期缺口不会被最近价或日线替代。当前网站读已保存数据，不自动调用Longbridge；取得数据后经手动入口补齐。
- regular与all请求的重叠分钟存在差异（AMD4条仅量不同；AMDL42条，其中39条涉及OHLC）。两种模式按独立数据集保留，禁止悄悄拼接或把同一来源当独立核验。
- 所有导入行情保持`unverified`。格式、OHLC关系和同源日线一致性检查不等于跨供应商核验。分钟戳按来源原值保存，来源分钟定义未完成独立逐笔核验，不能当真实成交时点。
- 长期存储和向第二用户展示的许可尚未确认；本次不向普通用户开放研究行情，不启用持续下载、付费订阅或再分发。数据保留由管理员控制，没有自动定期覆盖旧数据。
- [美股日历](US-MARKET-CALENDAR.md)覆盖2025–2026年、DST、普通交易日和半日常规收市；半日市盘后边界尚未核实，因此不生成半日盘后K线。未知年份拒绝推导。

## 数据与并发

`0005`保留原始1m/1d、来源、导入批次、修订。`0006`仅新增研究分组、标记、版本状态、请求幂等和审计表。所有新表独立于旧records/strategies。

图表 `/api/research/chart` 1m每页1个日历日，其他分钟周期最多3个日历日，日线最多366日；返回完整度、缺失原因、窗口起止、源版本及下一页。聚合按会话起点锚定，短尾窗明确标记；缺失或未知成交量不补0。当前每次从持久库按版本重算，避免源修订后保留旧派生值。未来/未结束窗口不作为完成价格。

`/api/research/groups`、`/markers`、`/markers/preview`、`/markers/import`、`/markers/export`只允许管理员。写入要求Origin、JSON、request_id、expected_revision；相同请求安全重放，版本冲突409。引用行情会固定数据集和单根版本快照，价格空白仍为空白。

全量SQL备份/恢复沿用[部署说明](DEPLOY-WEB.md)。回退Worker代码无需删除新增表；不通过删表回退。完整恢复应先在新数据库验证备份；当前没有执行生产恢复演练。

## 权限与账号

`/users`允许管理员为指定人员开通账户、停用、改角色或重置密码；没有公开注册，部署不会创建真实普通用户。普通角色沿用`viewer`内部值，在界面称普通用户，仅允许股价对比和必要行情。

`0007`只新增DB用户、会话版本映射、账号审计。密码PBKDF2哈希，日志与列表不包含密码/哈希。密码或角色变更、停用后旧会话失效。环境管理的原admin密码保持不变；已按用户要求取消的登录重试锁定不恢复。
