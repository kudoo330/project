# 数据字典与统计口径

- `strategies`：稳定ID、名称、归档状态。重命名不改样本关系。
- `batches`：请求幂等ID、创建者、创建时间、规范化输入摘要。相同ID同内容返回既有提交；同ID不同内容冲突。
- `records`：稳定样本ID、批次、策略、版本、证券、输入与上海时区标准化时间、人工成交价、参考价、股数、理由、标签、备注、定价状态、定价证据、行情快照、获取时间、错误、乐观锁版本、创建与修改时间。
- `checked_through`：管理员手动核对公司行动及价格可比性的截止日期；空值不输出正式累计涨幅。变更写入audit。
- `audit`：修改 / 删除前样本值、操作者、时间。只保存在服务端数据库，不输出到日志。
- `market_cache`：按证券和频率共享行情缓存，5分钟过期；样本身份不共享。
- `sessions`：令牌摘要、角色、账号、到期时间；无明文令牌或密码。
- `login_limits`：IP摘要、失败 / 待验证次数、窗口到期时间；不记录IP原文。

P0 = 人工成交价优先，否则经验证的分钟参考价。当前分钟自动定价未启用。D+n=(Cn/P0−1)×100。无P0、无完整日线、超出人工核对范围或日历不可用，结果为空。

D0不计后10日。最大上涨 / 下跌只取D+1—D+10已有有效收盘收益与0的最大 / 最小；全空仍为空。样本尚未完整时不是最终10日结果。

策略均值按该列有效策略样本等权计算，正收益比例为收益>0的样本数 / 有效样本数；0收益参与分母，不算正收益。跨策略不去重，不先平均各策略均值。

MA5/10/20为最近完整收盘均价；成交量比为最近完整日成交量 / 前5个完整日均量，前5日明确排除最近日。未复权指标可能受公司行动影响。

当前未接通可靠停牌与公司行动源，所以缺报价只标“缺少有效报价”，不能自动称停牌。超过日历覆盖不生成日期。不完整分钟不生成买入后极值。
