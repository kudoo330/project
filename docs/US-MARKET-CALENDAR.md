## 聚合与缺口

- 只在同一数据集、价格口径、纽约日期、会话内，把 1 分钟原始数据聚合为 5/15/30/60 分钟。
- 窗口按 07:00、09:30、16:00 会话起点锚定；尾部短窗口保留实际长度。例如常规 60 分钟最后一根为 15:30–16:00，半日市为 12:30–13:00。
- 日线必须选择独立日线数据集，不从全天分钟数据生成。
- 规范时间为 UTC；通过 IANA `America/New_York` 转换夏令时，不硬编码 UTC-4。
- 缺失、权限受限、请求失败、供应商明确无合格成交分别保留。未知缺口不补零、不延用前值、不推断停牌。聚合含未知缺口时标记 `partial`；OHLC 仅来自已存在的分钟，不声称完整窗口。
- 成交量与价格分别判断：即使某一分钟的 OHLC 缺失，已提供的成交量仍保留，并可进入成交量聚合。成交量为 0 时保留 0；窗口中任一分钟成交量未知，聚合成交量为空；超出安全整数范围也留空并说明。
- 无合格成交分钟有明确原因时计入已说明覆盖，但没有价格；`percent` 是有价格或有明确无合格成交说明的覆盖率，`price_percent` 单独表示有价格覆盖率。
- 尚未结束的窗口不作为完成 K 线返回。半日市之外的未来窗口也不计入已完成覆盖分母。
- 结果带数据集版本；每次按数据库当前原始分钟重算，不保留可能过期的派生缓存。读取期间版本变化返回 `409 dataset_changed`，由客户端重新载入。
- 1 分钟图按 1 个日历日分页，5/15/30/60 分钟图按最多 3 个日历日分页，日线最多 366 个日历日。响应提供 `next_cursor`，不会静默截断记录。
- 所有手工载入的行情仍是 `unverified`；日历复核不等于行情价格的独立源交叉验证。

## 本地验证

执行 `node --import tsx --test test/research-chart.test.ts`，**8 项通过**。覆盖 DST 春秋转换、休市、完整与半日交易时长、60 分钟短尾、07:00/20:00 边界、缺口与空成交量、缺价格但已知成交量、修订后重算、独立日线，以及真实隔离 D1 数据库分页读取。测试行情为隔离合成夹具，不写入生产。

开源日历复核可复现：

```python
import exchange_calendars as calendars
calendar = calendars.get_calendar("XNYS", start="2026-01-01", end="2026-12-31")
print(len(calendar.schedule))  # 251
for day, session in calendar.schedule.iterrows():
    close = session["close"].tz_convert("America/New_York")
    if close.hour != 16:
        print(day.date(), close.strftime("%H:%M"))
# 2026-11-27 13:00
# 2026-12-24 13:00
```
