# 双源收盘证据补齐

用户授权补齐并验证已导入记录。优先东方财富；其不可用时使用新浪不复权日线，独立腾讯不复权日线验证。东方财富可用而腾讯不可用时，可用新浪作为第二来源。绝不将同一来源自我验证；收盘价严格一致才写入。

管理员POST /api/import-closes，body为quotes数组，每批最多8只，重复策略样本过多需拆批。每条提供symbol、primaryProvider（东方财富/新浪）、bars、secondaryProvider（腾讯/新浪且不同于主来源）、secondary、fetchedAt、evidence，以及可选corporateSource。证据为管理员在Codex真实查询后补入，非公开行情代理。价格、OHLC、日期、未来/盘中时间、两源一致性、观察窗口均由服务端再次校验，保留来源。无效批次不执行写入。已核验旧收盘价与新证据冲突时拒绝，禁止静默覆盖。

更新仅market_data、fetched_at、error、revision和updated_at；买入参考价、实际成交价、原始时间与定价证据不变。批次原子写入并审计，每条更新携带revision条件避免覆盖用户并发修改。

D0是实际买入日期，可直接用当日双源完整收盘与原始P0计算同日价格变化，两者同一原始价格口径。未来公司行动按原规则同时调整分子分母，不改变该D0比值；D+1至D+10仍执行完整公司行动验证。北交所D0无需推算交易日序，允许实际日线日期；其后十日按用户2026-10-19确认复用沪深日历，仍需执行除权核对。

后台自动请求补全明确User-Agent/Referer；东方财富对5xx限次重试一次，失败切新浪主来源；腾讯失败时允许新浪作独立交叉来源，但新浪已是主来源时必须保留缺失状态。每股最坏6个外部请求，每轮8只最多48，保留免费请求预算。未来数据源可达性仍须看实际部署响应，不保证免费来源持续可用。
