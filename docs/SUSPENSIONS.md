# 停牌显示

当前采用管理员按日期确认，未启用自动停牌判定。不能把接口超时、缺少报价、零成交量、涨跌幅为零或休市认定为停牌。免费停复牌接口2026-10-19在Codex环境不可达，没有生产识别验证。

股票详情逐日表格的“标记停牌”需填写公告或人工查询依据；仅允许已收盘的交易日、该股票D0至D+10范围内日期。确认同股票相关样本，保留管理员、时间和原因。若当天已有正成交量及有效价格则拒绝整批标记。可按日撤销，保存前值审计；查看者不可写，正常Origin与登录校验适用。

已确认日期在主表显示“停牌”，详情保留确认依据；价格、涨跌幅和图表点留空，不填零或前收，不进入收益分母。日期不顺延，D+10不延后。该日不作为缺价重试，也不计入待补价数量；其他日期照常采集。停牌信息在刷新及行情补齐后保留。新成交行情与标记冲突时显示“停牌标记与行情冲突”并阻断该日收益，不能静默隐藏成交行情。

记录更新增加revision，避免采集过程覆盖人工标记。重复样本一次最多20条，超过时拒绝，便于在免费D1预算内保留每条审计。
