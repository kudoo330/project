# 核验记录导入

管理员登录后，在买入追踪中点击“导入核验数据”，选择JSON数组文件并确认条数。每次最多250条、1.5MB，缺少的策略按名称新建；同名策略歧义或已归档会拒绝。写入一次D1原子批次，失败回滚；相同文件的重复提交不重复写入。其他导入ID若命中已有的同策略、同股票、同时点记录会拒绝整批，不覆盖。

每条包含strategy、symbol、name、buy_time（北京时间）、original_time（可选）、reference_price、reference_evidence（来源证据）。参考价需要正数及证据；实际成交价与股数保持空。文件不包含market_data，收盘行情通过既有交叉核验任务另行采集。用户核验数据不提交Git。

用户当前规则：东方财富同分钟标签open优先，缺少有效open时用新浪补充，两源差异保留，不因价差拒绝参考价；手工指定价格记入manual_override证据。12:59:xx统一13:00:01，原始时间保留。参考价不代表成交价，分钟起止口径尚未独立核实，页面标记暂估。

D0与之后10个交易日分别采集，D0不占后续10日。除权与交叉验证门槛维持；北交所日历仍需验证。

验证：npm test、npm run check、npm run build、npm run test:import、npm run test:browser；本地模拟数据不能作为线上导入成功证据。线上必须看到成功响应并读取223条实际记录才能报告完成。

也可点击“批量 / CSV 导入”，粘贴Codex生成的制表符核验文字（必须保留表头），预览后确认。文字支持同一批250条、多策略、参考价、来源、原始时间与两源报价，使用相同权限与原子导入接口。
