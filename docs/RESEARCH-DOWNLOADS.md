# 管理员行情文件下载

聊天链接无法下载云工作区文件时，管理员可通过网站读取已准备好的ZIP行情包。文件只进入私有D1下载表，不放入公开Git仓库或静态资源目录。原有行情数据集、图表范围、回测和A股记录不因此修改。

- `POST /api/research-downloads`：现有管理员会话、同源JSON，提供安全ZIP文件名、说明、SHA256和base64文件内容。最大4MiB；请求流累计超过6MiB即取消。服务器核验哈希，以192KiB分块在一次D1事务中存储并记录审计。相同内容和说明可幂等重试，冲突说明拒绝。
- `GET /api/research-downloads`：列出未过期的文件元数据。
- `GET /api/research-downloads/download_<sha256>`：仅管理员下载；服务端重组并验证长度、分块顺序、完整SHA256后返回ZIP附件。未登录401、查看者403，过期410、损坏不返回文件。有效期7天。过期文件不公开，也不新增定时任务；本版未自动清理到期存储。

文件内容与准备时的来源口径须另附说明。源文件一致性核验不等于独立第二行情源价格交叉验证；不能把下载文件条数当作网站已保存条数，也不能把盘前盘后无返回K线自动认定为无成交。

## 自选时间下载（0.8.3）

AMD行情页的「下载行情」可选来源、美东起止时间和盘前/常规/盘后。结束分钟包含在内；独立日线按日期包含首尾。新只读接口 `GET /api/research-data/export-range` 导出已保存原始行，包含UTC与美东时间、OHLCV、状态/原因、来源及版本。缺失价格为空、成交量0保留为0；不推断无成交、不复用前价。CSV单元格沿用公式注入防护。读取分批进行，最终核对来源版本与条数，超过50万行或64MiB拒绝整个导出，没有静默截断；旧5000行导出接口保持兼容。

自选下载与网站来源一致。当前Alpaca网站分钟源保留07:00以后的盘前；已准备的原始ZIP包含04:00起行情，独立放在完整行情包中，不能混称为同一数据范围。下载和图表查看都不会改写行情或回测快照。
