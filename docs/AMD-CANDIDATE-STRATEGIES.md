# AMD 候选策略实验（0.8.0，待验收）

本轮依据用户上传的 `AMD_Strategy_Spec_All_In_One_v2.txt`（正文自称合并版v1.0 / 2026-10-28）开发。用户明确确认「只研究AMD，成交也用AMD」。这条确认覆盖附件的AMDL成交标的：本轮没有恢复AMDL，不用AMD涨幅乘2，不生成AMDL合成价格。本文记录已实现的兼容映射、可复现方法和边界；不是已验证盈利的交易系统。

## 与现有平台的兼容

保留 `/home` 左侧A股、右侧 `/backtest`。行情仓库、独立日线、会话日历和手动标注继续使用。新增候选策略实验面板在原研究图下方；手动假设、用户报告交易、算法研究信号、模拟成交分别存储和显示，不相互转换。原 `records/strategies`、D0—D10、收盘Cron、普通用户账号权限均不改。

`src/amd-backtest.ts` 提供无网络、无数据库的确定性纯函数；五个manifest和默认参数在同文件集中声明。`src/research-contracts.ts` 保留旧接口，不把人工标注的candidate/confirmed状态改成算法状态。新事件显式使用 `research_signal`、`simulated_fill`、`RESEARCH_ONLY`；持仓为 `LONG_AMD/CASH`。

## 研究规则

- BH00仅按外部给定的初始分钟open一次性买入整数股，保留余款，期末不强制清仓。
- D01：3根之前close至当前close跌幅≥1%、前8根低点破位、当前量≥前20根量中位数1.5倍、已闭合5m转弱，至少25根1m，最少持有15分钟。
- D02：此前20根close加当前close共21个价点的滚动跌幅≥1.4%、前10根低点破位、完整5m跌破此前3根5m低点且低于EMA8；当前确认5m必须属于本会话；最少持有20分钟。
- D03：前一交易日及之前20个独立日线计算SMA10/SMA20，当日UP/WEAK不变；最近60个已完成1m（含当前）高收盘至当前跌幅分别≥2.5%/1.6%、前10根低点破位、本会话最近两根5m均低于各自EMA20且继续走低；最少持有30分钟。独立日线不足20个连续交易日不判断。
- D04：Wilder ATR14/已完成5m close归一化，阈值clamp(1.8×ATR比率,0.8%,2.5%)；当前close相对5根之前跌幅触发，前8根low破位、已完成5m走低、量比≥1.25；最少持有15分钟。卖出信号时冻结买回反弹阈值clamp(0.8×ATR比率,0.5%,1.2%)，不使用未来ATR优化。
- R01 A：离场后最低**收盘**反弹0.8%（D03为1%），突破前5根close，且本会话已完成5m走高。
- R01 B：离场后最高close较卖出时AMD参考上涨1.2%，在**后续分钟**发生≥0.5%回踩，再在**更晚分钟**突破前3根close并有已闭合5m改善。无回踩不追涨，期末现金不强制买回。A和B同时满足优先A，但记录两个条件。
- 每次实际模拟成交后冷却15个实际时钟分钟（包括SELL后的买回等待）；初买/买回后的最少持有时间另行遵守。冷却中继续记录离场后的极值及回踩过程，但不生成新信号。

EMA使用首N根完整5m的SMA作为种子，再以2/(N+1)递推。Wilder ATR首14个TR均值作种子，首根TR=high-low，再以(13×ATR+TR)/14递推。ATR/EMA可跨会话、交易日预热；缺分钟或未知成交量造成5m不完整时重置受影响5m窗口。1m滚动窗口在会话边界及缺分钟后重新积累，不把盘间/跨夜空白当连续几分钟。此保守选择及其预热损失在质量报告中保留，不回填信号。

## 时钟和撮合

每个源1m按 `[time,time+60s)` 处理，仅在结束时决策。5m按07:00、09:30、16:00的会话起点对齐，5个有效且已完成分钟齐全才计算，不跨会话。前N根永远排除当前；D03的60根高收盘窗口单独按含当前定义。只读取已保存历史行情，不查询券商账户。

初始分钟open是给定的外部建仓假设，显示 `AMD_1M_OPEN_AT_TIME`，不是预测买点。其他信号于1m结束时产生，下一根分钟的open可从同一时刻开始作为候选成交。例如09:35—09:36 bar在09:36完成，最早候选是09:36开盘。默认再允许延迟1分钟，5分钟可作敏感性配置；不会把隔天开盘塞入这个窗口。

`IDEAL_OHLCV`只检验有效历史分钟，理论整仓成交，明显乐观。`VOLUME_LIMITED`再要求拟成交全部股数≤分钟volume×参与率，且volume≥最低量，不部分成交。分钟最终量只用于事后执行资格，**不回头屏蔽已生成的信号**。缺价等待至期限，低量候选立即记NOT_FILLED；成交前不切换持仓。没有初始有效建仓时返回NOT_COMPARABLE、资产/收益/对比为空，不把现金表现算成策略收益。

每种模型强制计算四档独立成本：单边0、10、20bp，及20bp + 盘前盘后额外20bp。成本视作成交金额的单边综合费用/滑点，成交后才扣；不重复扣两遍。所有模型/成本都使用独立BH00。现金不借贷、股数取整数、不裸空、不叠加杠杆。候选价、实际模拟价、成本、量资格、源版本均保留。

UI的结束时间是**包含该分钟收盘**：输入19:59，估值截止为20:00美东。日期和DST用IANA America/New_York，日历沿用2025–2026参考表。半日盘后时段未核实，仍不生成。其他年份拒绝猜测。

## 快照与存储

`0008_amd_backtests.sql`只新增run及parts两张独立表。新增接口均在已有服务器admin检查之后：

- GET `/api/research/backtests/strategies`、根路径历史清单。
- POST根路径：小型配置，服务端读取不复权AMD分钟/独立日线。最多184天、单来源最多15万行；分钟预热14日、日线预热90日。
- GET `/:runId`恢复结果；`/:runId/chart?date=YYYY-MM-DD&timeframe=1m|5m`读取当次保存的分钟快照，不读后来修订的源。
- GET `/:runId/export`导出完整输入、配置、版本、质量及逐笔。

写入要求Origin、JSON、请求ID；相同请求重试复用旧结果，不同配置复用ID拒绝。读取前后检查源版本，最终事务再次校验分钟与日线版本。输入以1000行分块归档，每策略/模型/成本一份结果；每块上限1.5MB，超过时明确报错而不静默截断。保存结果和源快照为一个D1事务，失败回滚。没有修改/删除旧结果的Web接口。普通用户、只读Token、未登录者都不能读取或导出。

信号、成交、仓位变化分开保存。所有策略使用相同的每分钟估值轴计算最大回撤；缺价时仅估值沿用已知价并记录陈旧分钟数，不能用于成交补价。前端净值曲线在同一轴抽样到约800点，完整逐笔不删；统计按全量分钟计算。期末空仓的最长等待包含截至期末的时间。

离线复现：用管理员导出的私有JSON，执行：

```bash
node --import tsx scripts/reproduce-amd-backtest.mts /private/path/amd-research-export.json
```

先核验输入SHA256和引擎版本，再严格比较所有事件、指标和质量报告。真实数据、导出、截图存于仓库外，不提交。
